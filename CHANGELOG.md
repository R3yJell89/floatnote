## [1.2] — 2026-09-18
### 🚀 Новые возможности и улучшения
- **Двусторонняя синхронизация маркеров с DaVinci Resolve**:
  - При добавлении задачи с таймкодом в чеклист маркер теперь автоматически создается на таймлайне DaVinci Resolve в нужную секунду и кадр.
  - На таймлайне маркер получает чистое имя задачи (без скобок и таймкода) и полное примечание.
  - В каждой строке чеклиста добавлена кнопка быстрой отправки маркера на таймлайн (`mappin.circle.fill`) с визуальной анимацией подтверждения установки `✓`.
  - В Настройки добавлен тумблер управления автоматическим созданием маркеров.
- **Стандартные кнопки управления окном macOS**:
  - В шапку FloatNote добавлены классические круглые кнопки macOS: **Закрыть** (красная с `✕` при наведении) и **Свернуть** (желтая с `—` при наведении).
  - Плавная анимация проявления глифов при наведении курсора в полном соответствии с гайдлайнами macOS Human Interface Guidelines.
  - Кнопка Pin теперь отвечает за закрепление окна поверх всех окон (Always on Top), а скрытие/закрытие выполняется нативными кнопками окна.
- **Модульная архитектура исходного кода**:
  - Монолитный код разделен на изолированные компоненты: `UIComponents.swift`, `AudioNotesView.swift`, `ChecklistView.swift`, `NotesView.swift`, `NLEBridge.swift`.
  - Централизованное управление путями хранения через `AppConstants.filesDirectory` (`~/Documents/Давинчи/FloatNote_Files`).

## [1.1.0] — 2026-09-18 — Первый публичный релиз (First Public Release)

> *Первый официальный публичный релиз FloatNote. Все предыдущие версии являлись закрытыми бетами.*  
> *«добавили больше багов, чтобы можно было исправить» 😉*

### 🧩 Модульная архитектура: FloatNote Core + DaVinci Companion Plugin
- **Полная независимость ядра**:
  - FloatNote Core полностью отвязан от конкретных программ монтажа и может использоваться с любым видеоредактором на macOS (DaVinci Resolve, Adobe Premiere Pro, Final Cut Pro, CapCut, Avid Media Composer).
  - Интерактивные бейджи таймкодов `[00:01:24:00]` работают в режиме Click-to-Copy: моментально копируют таймкод в буфер обмена для быстрой вставки.
  - Кнопка `⏱ Таймкод` вставляет таймкод из буфера обмена или стандартный шаблон.
- **Официальный плагин для DaVinci Resolve**:
  - Вынесен в отдельный каталог `Plugins/DaVinciResolve/`.
  - Включает Python-скрипт `FloatNote_Bridge.py` для прямой интеграции через официальный DaVinci Resolve Scripting API (синхронизация плейхеда, экспорт маркеров с комментариями и цветами).
  - Однокликовый скрипт установки `install.sh` в системное меню `Fusion/Scripts/Utility/`.

---

### 🪟 Отдельные плавающие окна-компаньоны (Companion Floating Windows)
- **⏱ Таймер монтажа & Помодоро (Stopwatch & Pomodoro 25/5)**:
  - Вынесен в **отдельное независимое плавающее окно** уровня `1002`, не перекрывающее основной интерфейс.
  - Режим секундомера для замера общего времени работы над проектом.
  - Режим фокус-сессий Pomodoro (25 минут работы / 5 минут перерыва) со звуковым оповещением и счетчиком сессий.
- **📋 Менеджер истории буфера обмена (Clipboard History)**:
  - Вынесен в **отдельное независимое плавающее окно**.
  - Фоновый перехват скопированных фрагментов текста (до 50 записей).
  - Удобный поиск по скопированным фрагментам, быстрый возврат в буфер в один клик для мгновенной вставки в титры, генераторы текста или инспектор.

---

### 📐 Прозрачный оверлей безопасных зон 9:16 (Safe Areas Overlay)
- **Полноэкранный прозрачный оверлей для вертикального видео** (Reels, TikTok, YouTube Shorts, VK Клипы):
  - Точные визуальные границы кадра с соотношением сторон 9:16.
  - Выделенные зоны интерфейса соцсетей с подписями:
    - **Верхняя зона UI** (поиск, аватар профиля, шапка).
    - **Правая колонка кнопок** (лайк, комментарии, репост, звук).
    - **Нижняя зона UI** (титры, описание, название аудиотрека).
    - **Центральный прицел (Crosshair)** для центровки ключевых объектов и лиц.
  - Кнопка блокировки (`Lock`): оверлей переходит в режим 100% сквозного клика (`ignoresMouseEvents = true`), позволяя монтировать видео прямо под сеткой.

### 📸 Захват кадра в скетчер (Frame Grabber into Canvas)
- **Аннотирование видеокадров**:
  - Кнопка `📸` в панели скетчера запускает быстрое выделение области экрана или вьювера монтажки.
  - Захваченный стоп-кадр моментально помещается фоном на холст рисования.
  - Поверх реального кадра можно рисовать стрелки, рамки, круги, линии и пометки для колориста или монтажера.
  - Экспорт размеченного кадра в PNG в один клик (`FloatNote_Files/Скетчи/`).

---

### 📋 Система шаблонов чеклистов (Workflow Templates Engine)
- **Встроенные готовые пресеты для монтажеров**:
  - *🎬 Предэкспортная проверка* (LUFS, offline media, титры, safe zones).
  - *🎨 Цветокоррекция (Color Grading)* (баланс белого, матчинг, skin tones, scopes).
  - *✂️ Черновой монтаж (Rough Cut)* (отбор дублей, A-Roll, перебивки, ритм).
- **Пользовательские шаблоны**:
  - Сохранение текущего набора задач в виде именованного шаблона.
  - Хранение в JSON с возможностью быстрого применения и удаления.

---

### 🎙 Голосовой ввод (Speech-to-Text)
- **Локальное распознавание русской и английской речи**:
  - Интеграция `SFSpeechRecognizer` и `AVAudioEngine`.
  - Диктовка задач в чеклист и текста заметок без переключения на клавиатуру.
  - Визуальная индикация активной записи («Слушаю...»).

---

### 🛠 Улучшения интерфейса и UX
- **Интерактивная булавка (Interactive Pin)**: клик по иконке скрепки скрывает окно с экрана (повторное открытие по хоткею `⇧ Space`).
- **First Mouse**: каждый элемент интерфейса реагирует с первого клика мыши даже из неактивного состояния без двойных нажатий.
- **Окно поверх Fullscreen Spaces**: окно FloatNote корректно держится поверх полноэкранных NLE без слёта пространств Spaces Mission Control благодаря флагу `.nonactivatingPanel` и уровню `1002`.
- **Поддержка светлых тем**: кастомный скроллбар с контрастной обводкой и фоном, видимый на любом цвете подложки.
